# WARGA QUICK START GUIDE (1 HALAMAN)

1. **Login**: Masukkan NIK dan Password Anda di portal SMART RT.
2. **Periksa Profil**: Buka menu Profil untuk memastikan data keluarga sudah benar.
3. **Ajukan Surat**: Pilih menu 'Pengajuan Surat', isi jenis surat dan alasan.
4. **Cek Status**: Pantau status pengajuan (Pending → Verifikasi Pengurus → Disetujui Ketua RT).
5. **Bayar Iuran**: Cek status iuran bulanan dan unduh bukti pembayaran.
6. **Buat Pengaduan**: Gunakan menu Pengaduan jika ada masalah lingkungan.
7. **Gunakan AI (Rita)**: Klik widget Rita AI di kanan bawah untuk bertanya info RT.
8. **Logout**: Selalu logout setelah selesai menggunakan komputer publik.
