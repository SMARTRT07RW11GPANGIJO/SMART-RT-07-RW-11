# ADMIN QUICK START GUIDE (2 HALAMAN)

1. **Akses Admin Control Center (9J)**: Login dengan kredensial Administrator utama.
2. **User & Permission Management**: Tambah pengguna baru, atur role, atau nonaktifkan akun jika mutasi.
3. **Pemeriksaan Daily Snapshot Backup**: Verifikasi ketersediaan file snapshot harian dan kecocokan SHA-256 Checksum.
4. **Monitoring System Health**: Buka Dashboard System Monitoring 24 jam untuk memeriksa latensi API, WhatsApp Gateway, dan Google Sheets status.
5. **Security Audit Review**: Buka Cryptographic Audit Log, pastikan status chain `VALID` dan tidak ada aktivitas mencurigakan.
6. **Deployment Check**: Saat ada pembaruan versi, jalankan pre-flight test, build `npm run build`, dan pantau status Vercel deployment.
