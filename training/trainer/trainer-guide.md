# PANDUAN TRAINER (TRAINER GUIDE)

## Peran Trainer
1. Menyampaikan materi teori, mengarahkan demo, dan mendampingi praktik.
2. Memastikan peserta mengikuti instruksi keamanan data tanpa kompromi.
3. Menilai hasil Ujian Teori (30%), Praktik (50%), dan Security Test (20%).
4. Mengarahkan peserta yang tidak lulus (<80% atau gagal Security Test) ke program Remedial.
5. Memverifikasi kelayakan peserta sebelum mengusulkan penerbitan Sertifikat & Aktivasi Role.

## Aturan Penilaian Compulsory Security
- Jika peserta mendapatkan nilai total >= 80%, tetapi GAGAL pada Security Test (<100%), peserta DIANGGAP GAGAL (REMEDIAL REQUIRED).
- Tidak ada toleransi untuk pelanggaran keamanan data (seperti menganggap pembagian password atau leak NIK adalah hal sepele).
